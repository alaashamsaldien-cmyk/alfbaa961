# School map candidates

`basra.json`, `nineveh.json`, and `additional-governorates.json` contain school points extracted from the [Geofabrik OpenStreetMap Iraq extract](https://download.geofabrik.de/asia/iraq.html) with data through 13 November 2026. The entries are grouped by the OpenStreetMap district polygons that contain them. Each identifier preserves the OpenStreetMap element type and ID. The groups describe the source boundaries and may differ from official administrative listings.
